================================================================================
                         DATA FLOW & REQUEST LIFECYCLE
================================================================================

1. Client Request (Angular Frontend)
   │
   ├─→ HTTP Request (GET/POST/PUT/DELETE)
   │   to http://localhost:8080/api/*
   │
2. Spring Boot Server
   │
   ├─→ CORS Filter (WebConfig)
   │   Validates origin, methods, headers
   │
3. DispatcherServlet
   │
   ├─→ BillingController
   │   @RestController maps request to handler method
   │
4. Controller Layer
   │
   ├─→ Validates request
   ├─→ Calls BillingService
   │
5. Service Layer
   │
   ├─→ Business logic processing
   ├─→ Calls Repository
   │
6. Repository Layer
   │
   ├─→ JpaRepository methods
   ├─→ Hibernate Query Generation
   │
7. Database Layer
   │
   ├─→ SQL Execution
   ├─→ Data Persistence/Retrieval
   │
8. Response Path (Reverse)
   │
   ├─→ Database → Repository → Service → Controller
   ├─→ JSON Serialization (Jackson)
   ├─→ HTTP Response to Client
   │
9. Frontend receives and displays data
